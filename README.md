# mytodo Skill

> 一句话整合你笔记里散落的待办事项。AI 自动分类、汇总到一张表、完成的自动归档。

## 它能做什么

把散落在「笔记收件箱」里的待办笔记，整合成一张分类清晰的汇总表：

- 🔍 **自动扫描** — 找出收件箱里所有待办类型的笔记
- 🤖 **AI 智能分类** — 自动归入 💼 工作 / 🎓 学习 / 📂 项目 / 🧘 生活
- 📋 **一张表汇总** — 所有待办统一展示，不再遗漏
- ✅ **完成即归档** — 打勾的任务下次整理时自动移到「已完成」区

## 适合谁用

使用 Markdown 笔记管理待办事项的用户：

- Obsidian 用户
- 本地 Markdown 文件夹（如 `~/Documents/Notes/`）
- 任何支持读写本地 Markdown 文件的 AI Agent 工具

## 快速上手

1. **安装 Skill**
   - 下载本仓库的 `mytodo.skill` 文件
   - 在你的 AI Agent 工具中导入（Claude Code / QoderWork / 其他兼容工具）

2. **配置路径**
   - 第一次运行时，告诉 AI 你的 inbox 和归档目录
   - 例：「我的 inbox 在 `~/Documents/Notes/Inbox/`，归档目录是 `~/Documents/Notes/Archive/`」

3. **记待办**
   - 在 inbox 里用 `YYMMDD_待办_主题.md` 格式新建笔记
   - 例：`260602_待办_周五交季度汇报.md`

4. **整合**
   - 输入 `/mytodo` 或「整合我的待办」
   - 十几秒搞定，所有待办分类好放在 `[待办汇总].md`

## 待办笔记示例

文件名：`260602_待办_周五交季度汇报.md`

```markdown
# 周五交季度汇报

- [ ] 整理 Q2 数据
- [ ] 做 PPT 大纲
- [ ] 跟同事对齐数据口径
- [ ] 发给领导审核
```

可选状态标记（在正文里加）：
- `【暂缓】` — 归入暂缓区
- `【已完成】` — 直接归入已完成区

## 文件说明

| 文件 | 说明 |
|------|------|
| `SKILL.md` | Skill 的完整规范文档 |
| `mytodo.skill` | 打包好的 Skill 文件，可直接导入 AI Agent |
